## Preferences

- Keep communication down-to-earth; avoid overly profound language, avoid "It's not X it's Y" constructs
- With UI, avoid overuse of gradients, avoid thin borders on one edge
- Identify root cause befor fixing issues. Prove with evidence, then fix.
- Use `uv` as Python package manager. Always `uv run xxx` never `python3 xxx`, always `uv add xxx` never `pip install xxx`
- Never use emojis in code or in print statements or logging
- Keep README.md concise
